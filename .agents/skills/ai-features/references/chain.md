# Parse chain

The scanner takes an image from the camera, the gallery, or the samples. OCR: ML Kit on Android, Vision on iOS. The text then goes to the parser. The model, when it is present, returns a structure that matches the schema. An invalid reply does not become a transaction: the user stays on the review screen with what the rule-based parser extracted, or sees a parse error.

BYOK does not turn on silently. First the consent screen, then the key field, then storage in Keystore or Keychain. The key is not in State and not in logs.

The assistant creates transaction drafts and waits for confirmation. A question about the user's own data runs as a typed intent that calls an existing read-only use case. A new intent is added in our code, not described in the prompt.

The prompt does not receive an instruction to execute commands from the receipt text. Receipt text is passed as data.

Prompt API availability is checked on a device at Stage 4. If the engine is not registered, the interface does not promise an on-device model.
