# Server

The server is the last stage (Stage 6). Until then the app is meant to be fully offline. First the store without a server, then the cloud.

The server is a separate Gradle build in `server/`, not a module of the mobile project. The stack is Ktor.

Services, added one at a time:

- `api-gateway` — `Application.gateway()` answers `GET /health` with status 200 and the text `ok`. `main` binds `127.0.0.1:8080`. No other route. The process stores nothing.
- `auth-service` — `:auth-service` is a process. `Application.auth(accounts)` answers `POST /sessions`. `signIn` returns `SignIn.Accepted` only when the email matches one supplied account and the password matches its `PasswordVerifier`. `passwordVerifier` builds that verifier with PBKDF2-HMAC-SHA256, 600000 iterations, a 16-byte salt, and a 32-byte hash, then clears the password array. A mismatch, an unknown email, or a body that is not a JSON object with `email` and `password` is `SignIn.Rejected`. Both fields are printable ASCII without spaces, quotes, or backslashes. The password is 8 to 128 characters. The route returns 204 or 401 with an empty body. `main` binds `127.0.0.1:8081` and passes an empty account list, so it accepts no sign-in. The password, the email, the salt, and the hash are omitted from `toString` and from exception text. `refreshToken` returns 32 random bytes. `refreshFamily` stores only the SHA-256 of that token. `rotate` returns `Refresh.Rotated` when that hash matches the current token: the family id stays the same, the presented hash joins a remembered list of at most 8, and the result carries a new token. A remembered token returns `Refresh.Reused` and revokes the family. A revoked family, a mismatch, or an unknown token is `Refresh.Rejected`. `rotate` clears the presented array. The token and the hashes are omitted from `toString` and from exception text. `POST /sessions` does not call `rotate`, and `main` does not create a family. The process does not call Redis or PostgreSQL, does not store an account, and is not called by `:api-gateway`.

Data and infrastructure:

- PostgreSQL: `:database` is a library, not a process. `openPostgres(primary, replica)` opens one JDBC connection for `Postgres.write` and one for `Postgres.read`. The same host, port, and database is rejected before connecting. The password is a connection property and is omitted from `toString`. The module does not start PostgreSQL, does not create tables, and is not called by `:api-gateway`. The driver is `org.postgresql:postgresql` 42.7.14 (BSD-2-Clause). Licensee 1.14.1 does not map its published URL, so that coordinate is a reviewed exception.
- Redis: `:cache` is a library, not a process. `openRedis(endpoint)` opens one connection. `Redis.set` writes one value and `Redis.get` reads it. A missing key returns null. The password is omitted from `toString` and from exception text. The module does not start Redis, does not store a refresh token, does not apply a rate limit, and is not called by `:api-gateway`. No Redis client library is on the classpath.
- Kafka: `:queue` is a library, not a process. `openKafka(endpoint)` opens one client. `Kafka.publish` writes one record and `Kafka.take` reads the latest record. An empty topic returns null. The password is omitted from `toString` and from exception text. The module does not start Kafka, does not write an outbox, a dead-letter record, or an idempotency key, and is not called by `:api-gateway`. The client is `org.apache.kafka:kafka-clients` 4.4.0 (Apache-2.0). A test starts one KRaft broker.
- Photo storage: `:storage` is a library, not a process. `openR2(endpoint)` opens one S3 client for Cloudflare R2, or MinIO locally. `R2.put` writes one object with `Cache-Control: private, no-store`. `R2.sign` returns a GET URL that expires in 60 seconds. The library does not return object bytes, so a JVM service does not proxy the file. The password is omitted from `toString` and from exception text. The module does not start MinIO, does not store a receipt, and is not called by `:api-gateway`. No S3 client library is on the classpath. A test starts MinIO.
- Public static files are cached at the edge. Private receipts are served with `Cache-Control: private, no-store`.
- Edge: `:edge` is a library, not a process. `openEdge(tunnel, shield)` accepts only a proxied hostname, origin `127.0.0.1:8080`, TLS `full-strict`, HSTS, WAF, bot protection, and a rate limit of 100 requests in 60 seconds. `Edge.cacheControl(PublicFile)` returns `public, max-age=86400`. `Edge.cacheControl(Receipt)` returns `private, no-store`. The tunnel token and the Origin CA are omitted from `toString` and from exception text, and `Edge` does not keep them. The module does not start cloudflared, does not call Cloudflare, does not store a receipt, and is not called by `:api-gateway`. The layout is [docs/server/cloudflare.md](../server/cloudflare.md).

The client does not pin the leaf certificate: Cloudflare rotates it. Network is HTTPS only. Cleartext is forbidden.

On the client, the flag `finpulse.cloud.enabled` switches a source set in `:shared`. The default is false, so `offlineMain` is compiled and `:feature:account` is not linked. `cloudMain` includes `accountModule`. The API contract between client and server (OpenAPI or a shared KMP module) is chosen at Stage 6, not earlier.

Cloud references: ASVS, OWASP API Top 10, OWASP LLM Top 10. The threat model is updated at that stage, not once at the end.
