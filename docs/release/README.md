# Release

This directory is filled at Stage 5. It will hold:

- the release signing policy: `keystore.properties` in gitignore and the same secrets in GitHub Actions;
- answers for Google Play Data safety and Apple App Privacy;
- `PrivacyInfo.xcprivacy`, usage descriptions, `ITSAppUsesNonExemptEncryption`;
- the store graphics list.

The manual `release-android` workflow also appears at Stage 5, not now.

Before Stage 5, do not put a keystore in the repository and do not describe passwords in documents.
