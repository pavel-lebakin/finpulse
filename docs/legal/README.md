# Legal

The privacy policy is [index.html](index.html). GitHub Pages publishes this directory. The workflow is `.github/workflows/pages.yml`. It runs on a push to `main` that changes `docs/legal`, and when someone starts it by hand. The site root is this directory, so the policy is the Pages home page.

The repository owner turns Pages on once, with GitHub Actions as the source. The workflow does not contain a key.

Related, but in other files:

- [LICENSE](../../LICENSE) — sources may be read and built for evaluation. They may not be redistributed or published to stores.
- [NOTICE](../../NOTICE) and [THIRD_PARTY_NOTICES](../../THIRD_PARTY_NOTICES) — product copyright and third-party licenses.
- The in-app "Open source licenses" screen is built with AboutLibraries (Stage 4, settings).
