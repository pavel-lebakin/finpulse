### `core/common/AGENTS.md`

# :core:common

### `core/mvi/AGENTS.md`

# :core:mvi

Package `com.lebakin.finpulse.core.mvi`. Depends on `:core:common`.

Public types: `ScreenState`, `ScreenAction`, `ScreenViewModel`. State changes only through `reduce { }`. `launchCatching` maps an error to `AppError` and does not swallow `CancellationException`.

The reducer is an `object` with extension functions. Call from the ViewModel: `reduce { ScreenReducer.run { withItems(items) } }`.

Check: `scripts/check.sh :core:mvi:jvmTest :core:mvi:compileKotlinIosSimulatorArm64`.

### `tooling/architecture-tests/AGENTS.md`

# :tooling:architecture-tests

JVM module. Package `com.lebakin.finpulse.tooling.architecture`. It is not part of the app. Konsist reads the repository sources.

Production rules:

- Extensions of `object *Reducer` on a `*State` type are called only from `reduce {}`. `initial()` stays in `createInitialState()`.
- `Loadable` is the only sealed interface with that name, not a value class.
- `*Dto` and `*Entity` are declared and imported in a package with a `data` segment or in `com.lebakin.finpulse.core.database`.

Check: `scripts/check.sh :tooling:architecture-tests:test :tooling:architecture-tests:detekt`.
