### `core/ai/AGENTS.md`

# :core:ai

Package `com.lebakin.finpulse.core.ai`. Depends on kotlinx datetime and kotlinx serialization. No feature dependency.

Public types: `ReceiptReply`, `ReceiptCategory`, `ReceiptCheck`, `receiptPrompt`, `checkReceiptReply`.

`receiptPrompt` places receipt text between `RECEIPT_DATA_BEGIN` and `RECEIPT_DATA_END`. Those markers inside the text are broken so the block has one end. The instructions do not tell the model to follow commands from the receipt. `checkReceiptReply` accepts one JSON object with `merchant`, `amountMinor`, `currencyCode`, `occurredOn`, and `categoryName`. `amountMinor` is a positive integer of at most nine digits. A repeated key is rejected. Anything else is `ReceiptCheck.Rejected`. An accepted value is a `ReceiptReply`, not a transaction. No feature calls this module yet.

Check: `scripts/check.sh :core:ai:jvmTest :core:ai:compileKotlinIosSimulatorArm64 :core:ai:detekt :core:ai:licensee`.

### `core/network/AGENTS.md`

# :core:network

Package `com.lebakin.finpulse.core.network`. Depends on `:core:common` and the Ktor client. No feature dependency.

Public types: `HttpsClient`, `HttpReply`, `openHttpsClient`.

`HttpsClient.post` accepts an HTTPS URL. A 2xx reply returns `HttpReply`. Any other address throws `IllegalArgumentException` before the call. A transport failure throws `NoConnectionException`. Any other status throws `ServerStatusException` and does not include the response body. `CancellationException` is rethrown. Redirects are off, so a 3xx does not continue onto cleartext. The client does not pin a certificate and does not log the body or headers. Android and JVM use OkHttp. iOS uses the Darwin engine. OkHttp pulls `org.slf4j:slf4j-api:2.0.19`, a reviewed Licensee exception because its MIT URL is not mapped. The app manifest forbids cleartext in every build.

Check: `scripts/check.sh :core:network:jvmTest :core:network:compileKotlinIosSimulatorArm64 :core:network:detekt :core:network:licensee`.

### `feature/scanner/AGENTS.md`

# :feature:scanner

Package `com.lebakin.finpulse.feature.scanner`. Modules `:feature:scanner:api` and `:feature:scanner:impl`. Group `com.lebakin.finpulse.feature.scanner`.

`api` exposes `ScannerEntry`. It depends on `:core:common`. `openCapture` pushes the capture screen.

`impl` reads a receipt from the camera, the gallery, or a bundled sample. Samples skip recognition and go straight to the rule-based parser. The same text always produces the same draft. No network.

### `shared/AGENTS.md`

# :shared

Package `com.lebakin.finpulse`. Koin root and the application shell. Do not put features here.

Public entry points: `initKoin`, `appModule`, `FinPulseApp`, `prepareAndroidStorage`, `attachReceiptCapture`. iOS: `MainViewController()` and `doInitKoin()`. Framework `Shared`, static.

`appModule` opens the Room database, one preferences file, the secret store, and `HttpsClient`, and includes `ledgerModule`, `onboardingModule`, `insightsModule`, and `scannerModule`. `ComposeRootNavigator` is also bound as `RootNavigator`. `NoOpErrorReporter` is bound here. `platformModule()` is empty for now. `NavDisplay` starts at `OnboardingDestination.Launch` and registers the onboarding, insights, and scanner graphs. That binds the database, preferences, and the secret directory under `noBackupFilesDir`. `attachReceiptCapture` runs from `MainActivity` before the first frame.
